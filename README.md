# 🔐 Password Manager

Un gestionnaire de mots de passe sécurisé avec interface graphique.

## ✨ Fonctionnalités

- 🔑 Mot de passe maître pour protéger l'accès
- 🔒 Chiffrement AES-256 des données
- ➕ Ajouter des comptes
- ✏️ Modifier par double-clic
- 🗑️ Supprimer des comptes
- 📋 Copier un mot de passe en un clic
- 🔍 Recherche en temps réel
- 👁 Afficher/masquer les mots de passe

### Prérequis
- Python 3.8+

### Lancer le projet
```bash
pip install cryptography
python main.py
